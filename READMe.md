# Drilling Fluids Data Analysis Project

## Project Overview
This project demonstrates how to effectively perform data analyzing, data filtering, data cleaning, , and data visualization of laboratory drilling fluids data/information form different wellpads using Python.

## Skills Demonstrated
- Python programming language
- Data organization in tables (Nymph)
- Data cleaning with Pandas
- Exploratory Data Analysis
- Data Visualization through plotting graphs and scatterplots (Matplotlib & Seaborn)
- Working with complex engineering datasets

## Tools & Libraries Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn


## How to Run the Project
1. Clone this repository
2. Install the required libraries: `pip install -r requirements.txt`
3. Open the notebook in Jupyter Notebook or Google Colab
